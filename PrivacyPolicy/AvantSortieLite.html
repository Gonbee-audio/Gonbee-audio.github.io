Politique de confidentialité

Dernière mise à jour : 20 juin 2026

Cette politique de confidentialité explique comment l’application Avant Sortie Lite traite les informations lorsque vous utilisez notre application mobile.

1. Informations que nous collectons

Avant Sortie Lite ne nécessite pas la création d’un compte.

Nous ne collectons pas directement d’informations personnelles telles que votre nom, votre adresse e-mail, votre numéro de téléphone, votre adresse postale ou vos informations de paiement.

L’application peut enregistrer localement sur votre appareil certaines données simples liées à son fonctionnement, telles que :

  • les éléments de vos listes de vérification ;
  • l’état coché ou non coché des éléments ;
  • les modèles de listes que vous modifiez ;
  • vos préférences simples dans l’application.

Ces données sont stockées uniquement sur votre appareil et ne sont pas envoyées à nos serveurs.

2. Utilisation des informations

Les informations enregistrées dans l’application sont utilisées uniquement pour fournir les fonctionnalités principales de l’application, notamment :

  • afficher vos listes de vérification avant de sortir ;
  • mémoriser les éléments que vous avez ajoutés ou modifiés ;
  • conserver l’état de vos listes et modèles ;
  • améliorer votre expérience d’utilisation locale.

Nous ne vendons pas vos informations personnelles.

3. Publicité

Cette application peut afficher des publicités fournies par des services publicitaires tiers, notamment Google AdMob.

Ces services tiers peuvent collecter et traiter certaines informations, telles que les identifiants de l’appareil, les identifiants publicitaires, les données d’interaction avec les publicités, l’adresse IP approximative ou des informations techniques sur l’appareil, afin de diffuser, mesurer et améliorer les publicités.

Le traitement des données par ces services est régi par leurs propres politiques de confidentialité.

4. Services tiers

Avant Sortie Lite peut utiliser des services tiers pour certaines fonctionnalités, telles que l’affichage de publicités ou l’analyse technique de base.

Ces services peuvent traiter certaines données conformément à leurs propres règles de confidentialité. Nous vous recommandons de consulter la politique de confidentialité de Google :

https://policies.google.com/privacy

5. Stockage local des données

Les listes de vérification et les préférences créées dans Avant Sortie Lite sont enregistrées localement sur votre appareil.

Si vous supprimez l’application ou effacez ses données depuis les paramètres de votre appareil, ces informations peuvent être définitivement supprimées.

6. Partage des données

Nous ne partageons pas directement les listes, éléments ou préférences que vous créez dans l’application avec des tiers.

Toutefois, les services tiers utilisés pour la publicité peuvent traiter certaines données techniques ou publicitaires conformément à leurs propres politiques.

7. Sécurité

Nous prenons des mesures raisonnables pour protéger les informations traitées par l’application. Cependant, aucune méthode de stockage ou de transmission électronique n’est totalement sécurisée.

Comme les données principales de l’application sont stockées localement, la sécurité de votre appareil contribue également à la protection de vos informations.

8. Confidentialité des enfants

Avant Sortie Lite n’est pas destinée spécifiquement aux enfants de moins de 13 ans. Nous ne collectons pas sciemment d’informations personnelles auprès d’enfants.

Si vous pensez qu’un enfant nous a fourni des informations personnelles, veuillez nous contacter afin que nous puissions prendre les mesures appropriées.

9. Vos droits

Selon votre pays ou région, notamment si vous résidez dans l’Espace économique européen, vous pouvez disposer de droits relatifs à vos données personnelles, notamment :

  • le droit d’accès ;
  • le droit de rectification ;
  • le droit à l’effacement ;
  • le droit d’opposition ;
  • le droit à la limitation du traitement ;
  • le droit à la portabilité des données.

Comme les données principales de l’application sont stockées localement sur votre appareil, vous pouvez les supprimer en réinitialisant l’application, en effaçant les données de l’application ou en la désinstallant.

10. Conservation des données

Les données enregistrées localement restent sur votre appareil tant que vous utilisez l’application ou jusqu’à ce que vous les supprimiez.

Nous ne conservons pas de copie de vos listes de vérification sur nos serveurs.

11. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité de temps à autre. Toute modification sera publiée sur cette page avec une nouvelle date de mise à jour.

Nous vous encourageons à consulter régulièrement cette page pour prendre connaissance des éventuelles modifications.
