Politique de confidentialité

Dernière mise à jour : 20 juin 2026

Cette politique de confidentialité explique comment l’application Journal Bruit Lite traite les informations lorsque vous utilisez l’application mobile.

Résumé : Journal Bruit Lite est une application simple permettant de noter des bruits gênants du quotidien. L’application ne nécessite pas de compte, n’enregistre pas d’audio et ne collecte pas directement d’informations personnelles.

1. Informations que nous collectons

Journal Bruit Lite ne vous demande pas de créer un compte. Nous ne collectons pas directement d’informations personnelles telles que votre nom, votre adresse e-mail, votre numéro de téléphone, votre adresse postale ou vos informations de paiement.

L’application peut enregistrer localement sur votre appareil les informations que vous saisissez dans l’application, notamment :

  • la date et l’heure d’un bruit noté ;
  • le type de bruit sélectionné ;
  • le niveau sonore indiqué ;
  • les notes ou commentaires que vous ajoutez.

Ces informations sont stockées uniquement sur votre appareil afin de fournir les fonctionnalités principales de l’application.

2. Utilisation des informations

Les informations saisies dans l’application sont utilisées uniquement pour vous permettre de :

  • noter des bruits gênants ou répétitifs ;
  • consulter l’historique de vos notes ;
  • organiser vos observations par date, type de bruit et niveau ;
  • utiliser les fonctionnalités de base de l’application.

Nous ne vendons pas vos informations personnelles.

3. Enregistrement audio

Journal Bruit Lite n’enregistre pas d’audio. L’application ne demande pas l’accès au microphone de votre appareil.

4. Localisation

Journal Bruit Lite ne demande pas l’accès à votre position géographique. L’application ne collecte pas de données de localisation.

5. Stockage local

Les données que vous saisissez dans Journal Bruit Lite sont enregistrées localement sur votre appareil. Elles ne sont pas envoyées vers nos serveurs.

Si vous supprimez l’application ou effacez ses données depuis les paramètres de votre appareil, les informations enregistrées localement peuvent être supprimées définitivement.

6. Publicité

Journal Bruit Lite peut afficher des publicités fournies par des services tiers, notamment Google AdMob.

Ces services tiers peuvent collecter et traiter certaines informations, telles que les identifiants de l’appareil, les identifiants publicitaires, les données d’interaction avec les publicités, les informations de diagnostic et d’autres données techniques nécessaires à l’affichage, à la mesure et à l’amélioration des publicités.

Pour en savoir plus sur la manière dont Google utilise les données, vous pouvez consulter :
https://policies.google.com/technologies/partner-sites

7. Partage des informations

Nous ne partageons pas directement les notes que vous créez dans Journal Bruit Lite avec des tiers.

Toutefois, si l’application affiche des publicités, les services publicitaires tiers peuvent traiter certaines données conformément à leurs propres politiques de confidentialité.

8. Sécurité des données

Nous prenons des mesures raisonnables pour concevoir l’application de manière à limiter la collecte de données. Les notes créées dans l’application sont stockées localement sur votre appareil.

Aucun système de stockage ou de transmission de données ne peut toutefois être garanti comme totalement sécurisé.

9. Conservation et suppression des données

Les données saisies dans l’application restent sur votre appareil jusqu’à ce que vous les supprimiez dans l’application, que vous effaciez les données de l’application ou que vous désinstalliez l’application.

10. Enfants

Journal Bruit Lite n’est pas destiné spécifiquement aux enfants. Nous ne collectons pas sciemment d’informations personnelles auprès d’enfants.

11. Vos choix

Vous pouvez :

  • supprimer vos notes dans l’application ;
  • effacer les données de l’application depuis les paramètres de votre appareil ;
  • désinstaller l’application ;
  • gérer les préférences publicitaires depuis les paramètres de votre appareil ou de votre compte Google.

12. Modifications de cette politique

Nous pouvons mettre à jour cette politique de confidentialité de temps à autre. Toute modification sera publiée sur cette page avec une nouvelle date de mise à jour.
